# ケーススタディ学習 UI設計書

**作成日**: 2026年1月27日
**バージョン**: 1.0
**対象**: ALE（AI Learning Engine）ケーススタディ学習機能

---

## 1. 設計方針

### 1.1 モバイルファーストアプローチ

本機能は**モバイルファースト**で設計し、PWAとして既存のクイズ・コース学習と同等の体験を提供します。

| 項目 | 仕様 |
|------|------|
| 基準幅 | 375px（iPhone SE相当） |
| ブレークポイント | sm:640px / md:768px / lg:1024px |
| タッチターゲット | 最小44px × 44px |
| フォントサイズ | 本文16px以上（モバイル） |
| コンテナ | `container mx-auto px-4` |

### 1.2 既存UIとの整合性

- **Header/MobileNav**: 既存コンポーネント再利用
- **カラー**: `bg-background`, `text-foreground`, `primary`, `muted`等の既存テーマ変数使用
- **コンポーネント**: shadcn/ui（Button, Card, Progress等）使用
- **アイコン**: lucide-react使用

- 「次へ進む」は選択肢選択後にアクティブ化

## 6. アクセシビリティ対応

### 6.1 基本要件

| 項目 | 対応 |
|------|------|
| キーボードナビゲーション | Tab, Enter, Spaceで操作可能 |
| フォーカス表示 | `focus:ring-2 focus:ring-primary` |
| コントラスト比 | WCAG 2.1 AA準拠（4.5:1以上） |
| スクリーンリーダー | aria-label, role属性適切に設定 |

### 6.2 実装例

```tsx
// 選択肢ボタン
<button
  className="..."
  role="checkbox"
  aria-checked={isSelected}
  aria-label={`選択肢 ${option.id}: ${option.text}`}
  tabIndex={0}
  onKeyDown={(e) => {
    if (e.key === 'Enter' || e.key === ' ') {
      handleSelect(option.id)
    }
  }}
>
  {option.text}
</button>

// プログレスバー
<div
  role="progressbar"
  aria-valuenow={currentStep}
  aria-valuemin={1}
  aria-valuemax={totalSteps}
  aria-label={`ステップ ${currentStep} / ${totalSteps}`}
>
  <Progress value={(currentStep / totalSteps) * 100} />
</div>
```

## 7. 状態管理

### 7.1 セッション状態

```typescript
interface CaseStudySessionState {
  sessionId: string
  problemId: string
  currentStep: number
  totalSteps: number
  answers: Record<number, {
    selectedChoices: string[]
    reasoningText: string
    hintUsed: boolean
  }>
  startedAt: Date
  status: 'in_progress' | 'completed' | 'abandoned'
}
```

### 7.2 状態管理方針

- **セッション状態**: `useState` + APIとの同期
- **フォーム状態**: `react-hook-form`
- **グローバル状態**: 必要最小限（認証情報のみ`AuthProvider`）
- **キャッシュ**: `useSWR`または`React Query`（Phase 2以降検討）
