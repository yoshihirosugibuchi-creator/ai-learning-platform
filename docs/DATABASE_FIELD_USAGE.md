# データベースフィールド使用状況ドキュメント

## 概要
データベースの各フィールドの使用状況と将来計画を記録するドキュメント

---

## usersテーブル - 学習レベル関連フィールド

### learning_level (string | null)
**現在の使用状況**: 🟢 **アクティブ使用中**

- **用途**: ユーザーが自分で設定する学習レベル（個人設定・パーソナライゼーション用）
- **値**: `skill_levels`テーブルのIDを参照
  - 'basic' - 初級（新人〜入社3年目）
  - 'intermediate' - 中級（入社3-7年目、チームリーダー）
  - 'advanced' - 上級（マネージャー、専門家）
  - 'expert' - エキスパート（シニアマネージャー、業界専門家）
- **設定方法**: プロフィール画面でユーザーが直接編集
- **使用箇所**: 
  - `app/profile/page.tsx` - プロフィール編集・表示
  - `lib/precomputed-quiz-engine.ts` - クイズパーソナライゼーション
  - クイズ難易度調整のウェイト計算

### skill_level (string | null)  
**現在の使用状況**: 🔴 **未使用（将来機能用）**

- **現在の状態**: 全ユーザー一律で'basic'がデフォルト設定済み
- **将来計画**: XP経験値ベースの自動レベルアップシステム
  - 一定以上のレベル達成時の**称号システム**として使用予定
  - ユーザーの学習成果に基づく自動的なスキルレベル認定
  - `learning_level`（自己申告）vs `skill_level`（システム認定）の使い分け
- **実装予定機能**:
  - XP閾値によるスキルレベル自動昇格
  - 称号・バッジ表示機能
  - スキルレベルに応じた特別コンテンツアクセス

---

## skill_levelsテーブル
**現在の使用状況**: 🟢 **マスターデータとして使用中**

- **用途**: 学習レベルの選択肢マスターデータ
- **参照元**: `learning_level`フィールド、プロフィール選択肢
- **API**: `/api/skill-levels` 経由で取得
- **管理**: `lib/skill-levels.ts`, `lib/profile-options.ts`

---

## 開発時の注意事項

### ✅ 使用すべきフィールド
- **クイズパーソナライゼーション**: `learning_level`を使用
- **プロフィール表示**: `learning_level`を使用
- **難易度調整**: `learning_level`を使用

### ❌ 現在使用してはいけないフィールド
- **`skill_level`**: 将来機能のため、現在のロジックでは使用禁止

### 🔄 移行時の注意
- 将来`skill_level`機能実装時は、既存の`learning_level`ロジックと併用
- `learning_level` = ユーザー設定、`skill_level` = システム認定として区別
